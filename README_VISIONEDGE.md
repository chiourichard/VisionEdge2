## 2.2.1 多國語介面

- 即時檢測、檢測履歷、照片與錄影、設備設定，以及 Flow Studio 支援繁體中文、簡體中文、English、Español。
- 頂部使用單一「🌐」語言選單，不新增登入或額外操作步驟。
- 語言選擇保存在瀏覽器 localStorage；首次使用會依瀏覽器語言選擇，無法識別時回到繁體中文。
- 西班牙文採墨西哥產線常用、偏中性的工程用語。
- 動態狀態、單張拍照判定、History、Toast、常見後端錯誤與確認視窗會同步翻譯；產品名稱、SN、樣板名稱、Step 名稱與檔名等使用者資料保持原文。
- 多語只改 UI 顯示，不改 API payload、資料庫內容、產品/樣板名稱或判定邏輯。

## 日常操作

1. 開啟設備網址，直接進入「即時檢測」。
2. 按「啟動相機」。沒有產品時，也能預覽、拍照與錄影。
3. 進入「流程設定」，輸入產品名稱／料號並按「建立」。
4. 按「從相機擷取」，在固定畫面框選樣板，按「加入」建立步驟。也可載入圖片或影片。
5. 需要依步驟完成檢測時，開啟「依步驟順序檢測」。進階條件預設收合。
6. 按「儲存並套用」，再按「回即時檢測」。本次檢測會重置，選定產品直接生效。

錄影中請先停止錄影，再變更設定或套用流程。照片與錄影頁支援縮圖、搜尋及分頁。

## 已修正

- Flow Studio API 路徑錯誤，原本進頁即 404。
- 登入對話框、帳密驗證 API 與寫死帳密已移除；首頁直接開啟 Edge UI。
- 樣板、規則、產品與 SOP 變更以同交易的產品版本追蹤；原地更新與清空設定都能被辨識。
- 不同產品各自計算版本，修改其他產品不會中斷目前產品的檢測。
- 當目前產品已變更但未套用時，暫停推論並明確提示；不繼續沿用舊設定判定。
- 「儲存並套用」改為直接套用 Edge runtime，同時重建樣板快取、產品資訊與 SOP 引擎；相機未啟動時，於下次啟動生效。
- 套用失敗不再顯示成功；儲存與套用結果分開顯示。停止超時不啟動第二個相機流程。
- 後端禁止錄影中改設定／停相機／重新套用，也禁止重複啟動錄影。
- 停機或畫面過期後不允許把舊畫面當新快照；檢測未就緒時禁用結果快照與結果錄影。
- 相機中斷時結束錄影，避免同一檔案無提示跨越不同相機連線。
- 錄影檔完成封裝前禁止直接開啟或下載；軟體錄影完成前保留 active 狀態。
- 錄影時間由後端起始時間計算，刷新頁面不歸零。
- API 斷線時清除有效檢測狀態，顯示固定錯誤提示。
- 常用操作中文化、進階設定收合；流程開關支援鍵盤及無障礙狀態。
- 相機擷取可直接用來標註，不必下載再上傳；新步驟直接使用樣板名稱，可在流程內修改。
- 修正窄螢幕頂列溢出。媒體頁提供照片縮圖、搜尋及每頁 30 筆。
- 檢測警報聲在使用者點擊頁面啟用音訊後，依流程的警報聲設定播放。

## 更新方式

交付包不包含測試資料庫、測試影像或已安裝的套件。

停止既有服務後，以本版程式及 static 檔案更新設備。保留現場的 `db/`、`runtime_data/`、`uploads/`、`config/edge.ini` 與設備憑證；不要以範例設定覆蓋現場設定。重新啟動時會自動建立版本追蹤表與 trigger。

啟動：`python3 -u visionedge_server.py`。仍沿用現有 HTTPS 設定與設備啟動方式。

## 驗證與限制

- 2.2.0 基線原交付已記錄 6 組 regression tests 通過：label_flow_regression_test、flow_designer_test、live_flow_graph_test、visionedge_regression_test、edge_smoke_test、edge_consistency_test。
- 本次 2.2.1 修改已通過 Python compileall、`i18n_static_test.py`、`visionedge_i18n.js` Node syntax check，以及 edge_dashboard / flow_studio inline JavaScript syntax check。
- 目前檢查環境缺少 Flask/OpenCV runtime 且無外網，因此未在此環境重新執行完整 6 組 integration tests；部署到既有設備環境後應再跑一次原 regression suite。
- 2.2.0 原瀏覽器驗證範圍包含：免登入首頁、建立產品、相機未就緒提示、相機擷取、框選／加入步驟、儲存套用、回即時檢測並完成步驟、拍照、錄影保護、刷新後錄影計時、媒體列表與 768px 版面。2.2.1 另需在目標瀏覽器逐一點測四語切換與長字串排版。
- 使用本機合成影片，未連接實體 Qualcomm 相機。真機 QTI、4K 效能、錄影封裝與長時間運作仍需在設備驗收。
- 版本變更採明確套用，會重新啟動相機並重置當次 SOP；不保留進行中的工件進度。
- 警報聲受瀏覽器音訊啟用規則限制；先點擊頁面操作後才可播放。
