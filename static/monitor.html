🧩 條件群組 / Rule Groups
—
現場可從目前已建立的 template 中多選，設定 ANY/OR 或 ALL/AND。建議 coating 前/後外觀相容用 ANY/OR；不同必要檢查點則分成多個群組，最終仍為所有啟用群組都通過才 PASS。
🧩 規則群組 / Rule Groups
—
正式版邏輯：每個「規則群組」可從多個來源產品選擇 OK 樣本與 NG 樣本。OK 樣本依 ANY/ALL 判定可接受情境；NG 樣本任一命中會強制 FAIL。儲存後會複製成目前產品的本地樣本，不會受來源產品後續刪改影響。
